Preview: 

Proxy is a free, modular low-poly character creation set from OverScore Media. 

Along with a base model, a whopping 315 models for accessories and clothing are included. But we're giving this whole set away, as a thank-you to the Blender and gamedev communities for being so awesome. Working on this set has been an excellent learning experience.

Feel free to use Proxy in any project you wish, personal or commercial.

 

Update Notes (05-12-2024):

====

Introducing OverScore Proxy 1.5, the Expressions Update!

With hundreds of new clothes and accessories, you can create custom outfits like never before. And the base model has been overhauled to allow for basic facial expressions and improved clothing animation. It also has actual fingers now, instead of just blocky hands!

Granted, this update adds a significant amount of geometry to the base model and the new clothing items. But it's probably fair to say it's still low-poly (the base model now has ~3K triangles, versus the ~1K triangles of the base model from version 1.2.1). And the additional geometry was arguably necessary, because version 1.2.1 had problems with animating clothing (especially around the shoulders and back), and the face and body needed a bit of work. Besides, the low-poly look is being used for its aesthetic value and ease of modelling - not as adherence to a hard technical limitation.

The version 1.2.1 base model is still included in this set if you need a lower-poly model. Be advised that many clothing and accessory items have been updated to fit the new base model, so they may be slightly incompatible.

Look out for future updates to this set - we have some interesting ideas cooking. Also, feel free to leave comments or suggestions for future updates, including new clothes or features!

====

 

Featuring:

  • 30 hairstyles
  • 20 glasses
  • 40 face items
  • 65 head items
  • 10 neck items
  • 25 hand items
  • 25 styles of footwear
  • 50 tops
  • 30 styles of legwear
  • 20 full-body outfits

Also featuring:

  • 11 realistic hair colours
  • 11 hair dye colours
  • 12 realistic skintones
  • 7 realistic eye colours
  • 6 realistic lip colours
  • 14 shape keys for facial and other animation

The preview images represent only a small fraction of the possibilities with this modular set.

And it's also worth mentioning that every model has been painstakingly creating using quads only.

Check out our blog post for more info on the low-poly modelling workflow we used to create this character: https://overscore.media/posts/series/low-poly-character-modelling-with-blender

Please Note: These models are unrigged, do not include UVs, and are untextured (using Principled BSDF Base Colours). So it will still take a bit of work to use them in a game engine.

However, you should be able to get a lot of mileage out of our Mixamo animation tutorial, if that's what you're going for: https://overscore.media/posts/low-poly-character-rigging-with-blender-and-mixamo

Keep an eye on this project; we will likely update it with new models and other features in the new future. In the meantime, we hope you enjoy!

---

Many items have a Mirror and/or Solidify modifier active. Inside faces have not been removed.

Blend file included. Created in Blender 4.0.2
